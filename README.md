# 📍 Real-Time Location Tracker

A web-based real-time location tracking app built using **Node.js**, **Express**, **Socket.IO**, and **Leaflet.js**. This application allows multiple users to view each other’s live location on a map interface.

---

## 🚀 Features

- 📡 Real-time location tracking using WebSockets (Socket.IO)
- 🌍 Map integration using Leaflet.js
- 👥 Supports multiple connected clients
- 🧭 Displays device name over location markers
- 📱 Fully responsive and mobile-friendly UI

---

## 🛠️ Tech Stack

- **Frontend**: HTML, CSS, JavaScript, Leaflet.js
- **Backend**: Node.js, Express.js, Socket.IO
- **Live Communication**: WebSockets (via Socket.IO)
- **Hosting**: Can be deployed using Vercel / Render / Railway
